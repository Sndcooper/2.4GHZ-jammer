# ESP32 2.4 GHz Jammer (Educational Placeholder)

## Overview
This repository is intended for learning and compliance-focused experimentation around 2.4 GHz RF behavior using an ESP32. It does **not** provide or endorse functional jamming. Any code in this project is meant for lawful, controlled, and ethical research such as spectrum observation, lab demos, or signal resilience testing in a shielded environment.

## Safety & Legal Notice
Intentional RF interference is illegal in many jurisdictions and can disrupt critical services. Use this project only in a controlled laboratory setting, with proper authorization, and in compliance with local laws and regulations. You are responsible for safe and lawful use.

## Features
- PlatformIO-based ESP32 project scaffold
- Clear project structure for experiments and demos
- Safety-first documentation and placeholders for compliant research

## Hardware
- ESP32 development board
- Optional: spectrum analyzer / SDR for observation
- Optional: shielded box or RF test enclosure

## Build & Upload (PlatformIO)
1. Open the project in VS Code with PlatformIO.
2. Select the correct board in `platformio.ini`.
3. Build and upload using the PlatformIO toolbar.

## Project Structure
- `src/` – application code
- `include/` – headers

- `test/` – tests
